## 使い方

### 画像→粒子変換

`white-background-removal-color-cast.jpg` を花火画像として読み込み、白背景由来の迷子のパーティクルが表示されないことを確認します。淡い色と濃い色の花火が残ることも確認します。

### 色の調整（管理画面の編集モーダル）

`white-background-removal-color-cast.jpg` は淡いピンク・水色・黄色と照明の色かぶりを含むため、
「🎨 色の調整」の確認にも使えます。「花火・印刷に残る部分だけ表示する」をONにして、

- プリセット `なし` に対して `ふつう` で淡い色（特にピンク）の残る面積が増えること
- `強め` にしても、白紙・照明の色かぶり・影が拾われ始めない（「残る画素」が跳ね上がらない）こと
- 「紙の色かぶりを自動で補正する」をOFFにして彩度を上げると、画像左右の色かぶりが拾われ始めること
  （＝この補正が効いていること）
- 「🎯 色ごとの強調」で全体を `なし` にしたままピンクだけを上げると、**淡いピンクだけ**が残るようになり、
  淡い水色・黄色と濃い赤は見え方が変わらないこと（色相の指定が効いていること）
- 「補正前」プレビューの淡いピンクの図形をクリックすると、`ピンク` の行が 2.2倍 に上がること。
  白紙の上をクリックした場合は設定が変わらず、警告だけが出ること（スポイトの判定）

を確認します。長方形の画像なので、「📄 用紙全体を収める」で長辺いっぱいの正方形が切り取れること、
はみ出した部分が白い余白になること（＝粒子・印刷に出てこないこと）の確認にも使えます。

### PDF・キーホルダー印刷

管理画面から画像を登録し、「PDFの生成」と「キーホルダーの印刷」をそれぞれ実行します。出力された花火画像の背景が透明で、色付きの図形だけが印刷対象になっていることを確認します。

`square-full-bleed-calibration.png` / `landscape-full-bleed-calibration.jpg` を登録した場合は、
生成されたPDF・印刷ページで画像が点線の切り取り枠からはみ出していないこと、4辺の色がすべて
見えていること、中央のモチーフが正立していることを確認します（issue #51 の回帰確認）。

`black-ink-preservation-calibration.png` を登録した場合は、粒子変換・PDF・印刷ページのいずれでも
黒い四角形・星形・細い線が消えずに残り、影・照明カブリング相当のグレー領域は従来通り除去される
ことを確認します（黒インクが除去される問題の回帰確認）。

`thin-marker-line-calibration.png` を花火画像として読み込み、画質設定「中」（resolution=64）
・「高」（resolution=128）のいずれでも、円の輪郭線・ジグザグ線が点線状に消えたり途切れたり
せず、粒子として残ることを確認します（マッキー・サインペン程度の太さの線が消える問題の
回帰確認）。

`small-dot-calibration.png` を登録した場合は、粒子変換・PDF・印刷ページのいずれでも、
直径8px以上の点（実写真相当の劣化込み）が消えずに残り、影・照明カブリング相当のグレー
領域は誤って拾われないことを確認します（小さい黒インクが検知できない問題の回帰確認）。

## 画像の由来

`white-background-removal-color-cast.jpg` はOpenAIの組み込みImageGenでテスト専用に生成した画像を、JPEG品質78へ変換したものです。外部サイトから取得した画像ではありません。

`square-full-bleed-calibration.png` / `landscape-full-bleed-calibration.jpg` は同ディレクトリの
`generate_full_bleed_calibration.py`（Pillow使用）で機械的に生成したものです。外部サイトから
取得した画像ではなく、再実行すればいつでも同じ画像を再生成できます。

`black-ink-preservation-calibration.png` も同様に、同ディレクトリの
`generate_black_ink_calibration.py`（Pillow使用）で機械的に生成したものです。

`thin-marker-line-calibration.png` も同様に、同ディレクトリの
`generate_thin_marker_line_calibration.py`（Pillow使用）で機械的に生成したものです。

`small-dot-calibration.png` も同様に、同ディレクトリの `generate_small_dot_calibration.py`
（Pillow使用）で機械的に生成したものです。ガウシアンブラー＋JPEG再圧縮で実写真相当の
劣化を加えています。
